# ElderCare - מערכת תכנון פעילות אישית לקשישים

מערכת לניתוח רב-מימדי של מצב הקשיש (רפואי, תרופתי, סיעודי, קוגניטיבי, נפשי, חברתי, משפחתי, דמוגרפי) ויצירת תוכנית פעילות יומית מותאמת אישית, שמתעדכנת מדי יום ומבוססת על בנקי ידע.

---

## איך מתחילים (פעם ראשונה)

### דרישות

- **מחשב Windows** עם חיבור לאינטרנט בפעם הראשונה.
- **Python 3.11 ומעלה** - אם אין אצלך, התקנה אוטומטית תתחיל בפעם הראשונה שתפעיל.

### הפעלה

1. **לחיצה כפולה על `run.bat`** בתיקייה הזו.
2. בפעם הראשונה זה ייקח 5-10 דקות (התקנת ספריות).
3. דפדפן ייפתח אוטומטית עם המערכת.

זהו - הכל מקומי, לא צריך שרת.

---

## איך משתמשים

### בתפריט הצדדי
- **שפה** - עברית / English
- **תצוגה:**
  - 👤 **פרופיל קשיש** (caregiver) - הזנת נתונים, תוכנית יומית, סימון ביצוע
  - 📊 **ניהול** (manager) - דוחות ומעקב על כל הקשישים
  - 📚 **בנקי ידע** (knowledge) - מחלות, תרופות, פעילויות

### זרימת עבודה רגילה

1. **הוסף קשיש** (תפריט צדדי → `הוסף קשיש חדש`).
2. **טאב פרופיל** - בחר אבחנות, תרופות, מצבים סיעודיים/קוגניטיביים/וכו'.
3. **קבע משקלים** - מה הכי חשוב לקשיש הזה (1-10 לכל ממד).
4. **קבע רמת תפקוד** (1-5).
5. **שמור**.
6. **טאב תוכנית יומית** → לחץ "צור תוכנית חדשה".
7. במהלך היום - סמן 'בוצע' או 'לא בוצע' עם סיבה.
8. **טאב מבחני יכולת** - הזן MMSE, TUG, Barthel וכו' מדי תקופה.
9. בצד ניהול - הפק דוח Word/PDF/Excel.

## איפה הקבצים שלי?


### עריכת בנקי ידע

הקבצים האלה הם **Excel רגיל**:
- `knowledge_banks\diseases.xlsx` - מחלות
- `knowledge_banks\medications.xlsx` - תרופות
- `knowledge_banks\conditions.xlsx` - מצבים (סיעוד/קוגניציה/חברתי/וכו')
- `knowledge_banks\activities.xlsx` - פעילויות ותרגילים

ניתן לפתוח, להוסיף שורות, ולשמור. אחר כך במערכת → "בנקי ידע" → "רענן בנקי ידע מ-Excel".

## עמודות ב-`activities.xlsx` (הכי חשוב)

| עמודה | משמעות |
|---|---|
| `code` | קוד ייחודי (ACT031, ACT032...) |
| `name_he` / `name_en` | שם בעברית/אנגלית |
| `category` | physical / cognitive / social / mental |
| `strengthens` | תגיות מופרדות ב-`;` למה הפעילות מחזקת |
| `contraindications` | תגיות למי **אסור** לבצע |
| `min_capability_level` | רמת תפקוד מינימלית (1-5) |
| `duration_min` | משך בדקות |
| `description_he` | הסבר |

תגיות ה-`strengthens` בפעילות **חייבות להתאים** ל-`needs_strengthening` במחלות/מצבים, אחרת המודל לא יבחר בפעילות הזו לקשיש שזה הצורך שלו.

## מודל האופטימיזציה

הקובץ `models\optimizer.py` רץ **בנפרד** (אפשר להריץ ידנית בלי הממשק):

```bash
python -m models.optimizer --elder-id 1 --date 2026-06-08
```

- אלגוריתם: ILP (Integer Linear Programming) באמצעות PuLP+CBC.
- מטרה: למקסם **התאמת צרכים × משקלי משתמש + בונוס העדפות**.
- אילוצים קשיחים: מגבלות מחלה/תרופה, רמת תפקוד, רשימת "לא רוצה".
- מתחשב בהיסטוריה: פעילות שכבר בוצעה ב-3 ימים אחרונים תקבל עונש קל (גיוון), פעילות שהקשיש סירב לה לאחרונה לא תוצע שוב.

## רב-לשוניות

קבצי תרגום: `locales\he.json`, `locales\en.json`.

הוספת שפה חדשה (למשל ערבית):
1. צור `locales\ar.json` עם אותם מפתחות.
2. הוסף בקובץ `ui\i18n.py` ב-`SUPPORTED` את `"ar": "العربية"`.
3. הוסף `"ar"` ל-`RTL_LANGS` אם הכיוון מימין לשמאל.

## תמיכה ופיתוח עתידי

- **שלב הבא:** חיבור ל-HL7 FHIR / ממשק קופות חולים, אפליקציית מובייל לקשיש/בני משפחה, הוספת בנק תוכניות חיצוניות (מרכזי יום, חוגים) פר עיר.
- **רישוי רפואי:** מערכת זו היא **כלי תמיכה** לאיש מקצוע. אינה תחליף לייעוץ רפואי.
